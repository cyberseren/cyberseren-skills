# palo-alto

Bundle plugin for Claude Code that installs every Palo Alto Networks plugin by CyberSeren. It contains no skill itself: each product plugin carries its own skills, so you get each skill once.

Included plugins:
- `prisma-browser`: create Access & Data Control rules in Strata Cloud Manager.

Install: `/plugin install palo-alto@cyberseren`. In other agents, install each product plugin; see the main README.
