# palo-alto

Bundle plugin that installs every Palo Alto Networks plugin by CyberSeren. It contains no skill itself: each product plugin carries its own skills, so you get each skill once.

Included plugins:
- `prisma-browser`: create Access & Data Control rules in Strata Cloud Manager.

Install: `/plugin install palo-alto@cyberseren`. To install one product only, see the main README.
