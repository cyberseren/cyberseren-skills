# palo-alto

Bundle plugin that installs every Palo Alto Networks skill by CyberSeren, in Claude Code, Codex, Cursor, GitHub Copilot and VS Code.

Included skills:
- `prisma-browser-access-data-control-rule`: create Access & Data Control rules in Strata Cloud Manager.

The skills in `skills/` are copies of the product plugins' skills, made by `scripts/sync-bundle.sh`. Edit the skill in its product plugin, then run the script.

Install: `/plugin install palo-alto@cyberseren` in Claude Code. For other agents and for one product only, see the main README.
